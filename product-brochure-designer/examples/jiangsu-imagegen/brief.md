# 水岸江苏：全生图海报与四页手册

本例继续使用已调研的南京—扬州—苏州六日旅行提案，分别测试单页传播与多页阅读。文字、插画和排版均由内置 ImageGen 完成；PDF 仅等比嵌入原图，不用 HTML、程序贴字或人工拼图修饰生成结果。四页是本例内容编辑后的选择，不是手册固定页数。

## 设计依据

用户认可此前日光版 HTML 的方向，本轮要求继续优化全生图海报和产品手册。保留从实景中获得的明亮、温润与生活气息，不照搬 HTML 布局，也不把江苏或所有旅行都限定为某种颜色。原六页 HTML 保留。

概念：水线串起三城。海报让水岸与大字共同建立记忆点；手册封面建立整体，南京用河街的纵深引入两天行程，扬州以开阔湖面配早茶细部形成疏密，苏州以园林空间的框景与路径组织收尾。城市图像是说明性插画，不作为实景摄影或精确地图。

| 全套保持 | 随任务变化 |
|---|---|
| 亮纸面、浅水色、自然绿与少量暖色，深灰文字 | 各页图文比例、主次、取景与构图 |
| 大标题与易读正文分工，细而清楚的水线 | 海报的一眼识别、封面的开篇、内页的连续阅读 |
| 相同的纸本插画材料感、页边与页码语言 | 城市空间、日程和辅助图像 |
| copy.json 中的准确文案与原提案事实 | 有编辑依据的换行与信息分组 |

## 内容与文件

- 准确文案：`copy.json`。本例是精简路线手册，未提供价格、具体班次、酒店承诺或门票套餐；每日选择和住宿是编辑建议。
- 事实依据沿用 [原产品资料](../jiangsu-waterways/product.json) 与 [研究及素材记录](../jiangsu-waterways/sources.md)。生图调用与素材角色见 `sources.md`，完整提示词在 `prompts/`，页序在 `booklet.json`。
- 先生成海报建立本轮画面语言，再生成南京这一真实内容内页检验密度，随后展开封面与另外两城。稳定代表页作为参考锚点，不只串联上一页。
- `reviewed` 表示 Agent 已查看、核对，不表示用户已认可，也不证明多页生成稳定性。最终像素、PDF 分辨率与阅读限制据实际文件记录。
