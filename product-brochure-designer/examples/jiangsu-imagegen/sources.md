# 水岸江苏全生图版：内容与制作记录

制作日期：2026-11-17。海报与四页手册为本次 Skill 改进的实际样稿，采用内置 ImageGen，没有使用 CLI／API 回退。交付页面的文字、插画、图文空间均由生图完成；没有用程序补字、拼图或覆盖修饰。`index.html` 是原图查看页，不是手册的排版源文件。

## 内容依据

沿用 [六日路线资料](../jiangsu-waterways/product.json) 和 [官方调研记录](../jiangsu-waterways/sources.md)。每日安排、二选一和住宿分配为旅行提案；未添加报价、酒店、固定班次或在售套餐承诺。图像是概念插画，不用作精确地图或实景摄影。

本轮重新读取 [苏州文旅的平江河街介绍](https://www.suzhou.gov.cn/gsbdbwlyjc/yshi/202008/12875852fc0845afa5534cc7b29c5b19.shtml) 与 [文旅部瘦西湖资料](https://sjfw.mct.gov.cn/site/dataservice/culdetails?curId=10&id=34860)，只采用河街日常、湖面桥亭等稳定内容；不引用评级年份、开放时间、价格等细节。秦淮区原入口本轮超时，保留上一轮已核对的内容，不据超时推断新事实。

文案主记录为 `copy.json`；每次实际调用的完整提示词在 `prompts/`，并在调用前保存。生成提示词能记录设计决策，不保证再生成逐像素一致。

## 取舍与核对

- 南京与扬州保留相近的日程导航，分别以河街纵深与开阔湖面／早茶细部组织画面；苏州初稿过度复制相同结构，实际用图像编辑重排。不能只因提示词写了“不同构图”就认为它已经做到。
- 查看全部最终原图，逐项核对标题、日程、段落、住宿与页码，另用系统 OCR 辅助定位。OCR 对装饰宋体、分隔点、床位图标有误识，回看实际字形判断；不把 OCR 结果自动当作正确文本。
- 画面没有加入设计者／工具署名、AI 标签、水印或通用免责声明。内容依据、过程与限制在本记录中，未占用旅行页面。
- 实际海报为1086×1448，四页均1055×1491；提示词的高分辨率要求没有变成额外像素。A4 PDF 等比完整嵌入原图，约127.6ppi，供屏幕放大审阅，不宣称达到300ppi印刷原稿。
- 栅格页面不含可搜索或可编辑的文字层，也不会在手机宽度重排；正文需要按实际观看情境检查，查看页提供原图与 PDF 放大入口。

PDF 的实际页序、嵌入像素和逐页渲染，以及 Skill 检查，见仓库 [本轮证据](../../../docs/research/evidence/2026-11-17-full-imagegen.json)。样稿由 Agent 检查，不等于用户已认可本轮效果，也不是跨题材或长手册生成稳定性的评测。
