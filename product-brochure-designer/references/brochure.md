# 多页产品手册

适用：产品宣传册、研学手册、旅游手册、销售手册、项目介绍与目录。A4 竖版是已有模板的默认值；用户指定别的尺寸时按要求设计。投影演示与交互网页使用相应工作流。

## 两种制作路线

- **生图视觉版**：模型完成各页整体设计，包括信息编排、图解、排字与图像。先编辑内容，再用真实内页验证内容量和表达关系是否可行；读 `image-generation.md`，逐页生成、核对、合成 PDF。用户选择这条路线时，不把它自动缩成以氛围插画为主的画册。
- **HTML 排版版**：适合长文、精确参数、频繁修改或可编辑文字要求。可以使用生成的素材，但页面主要内容由 HTML 排版。制作与导出见下文。

用户已经选路线时尊重选择；未选时根据文字密度、视觉要求和编辑需求推荐。不要默认所有手册必须走 HTML，也不要承诺生图页具有可编辑文字。两条路线都需要逐页核对内容与最终 PDF。

## 内容与页数

产品资料可以来自文档或对话。信息复杂或需要重复核对时整理为 `product.json`，可参考 `examples/sustech-study-tour/product.json`；它是含待确认项的草稿，不是真实项目背书。至少明确名称、描述与读者，保留已确认的参数和联系信息。

先分清单产品叙事或多产品目录，再按内容决定页数，**不限制为 6／8／10 页**。有装订要求时另按印厂规定安排页数与空白页。不要为了叙事结构注水，也不要遗漏必要的费用、条件与细则。

单产品常见顺序：核心定位 → 价值与证据 → 内容／流程 → 参数与必要条件 → 行动。多产品目录则重视产品页之间的可比较性与一致布局。呼吸页、故事页仅在确有内容作用时加入。

按实际读者任务检查整本的内容覆盖。例如旅行提案要能找到天数分配、换城、住宿和择一关系；研学手册要让学习目标、现场观察与记录任务相互对应；产品手册要支撑理解特征、判断适用性或使用产品。它们是用途线索，不是每本都要凑齐的固定栏目。每页先回答一个清楚的问题，整本连起来完成任务；不能让每张内页都变成同类宣传海报。

## 设计与 HTML

读共同设计原则后，按当前任务规划各页角色、主要内容、图像与布局。方案简单时无需另写 JSON；使用 `page-plan.schema.json` 时，让 pageCount 与 pages 数量一致。

新手册先把视觉概念落实到封面与一张真实内容内页，检查二者是否形成完整语言，再铺开整本。需要探索时见 `art-direction.md`。大标题、实景照片和清楚日程是可用元素，但它们的存在本身不能证明有设计感。

`templates/brochure.html` 演示 A4、打印规则和六类语义锚点。每页一个 `<section class="page">`；打印时固定页面尺寸，屏幕阅读可以自然重排。内容超出时编辑或分页，不能用隐藏溢出来掩盖丢失内容。统一页眉、页脚、字体和品牌，但按内容调整构图。

### HTML 的阅读与前端设计

本项目对 HTML 产品／研学／旅游手册的默认偏好是**字大、易读、排版精致**。下列是可调整的制作起点，不是适用于所有介质的统一标准；用户品牌与目标读者有明确要求时以其为准。

HTML 成品被反馈机械、缺少韵味，或需要建立整本的编辑气质时，读 [HTML 编辑与版面细节](html-editorial.md)。先从真实内页的叙事、文案、照片取景与排印关系修改，再延续到相邻页面。此处针对 HTML 排版，不据此评价或改动整页生图路线。

- A4 正文从 **14–16pt** 开始，章节标题约 **28–36pt**，行高约 **1.6–1.8**。非核心图注、来源与页码可用 **11–12pt**；行程、费用、预约要求和重要限制保持正文级别。放不下时先重组、减少重复或分页。
- 手机 HTML 正文约 **18–20px**，窄屏改为单列、自然增长。提供 viewport；不要用 transform、zoom 或整张 A4 等比缩小充当手机适配。手机 PDF 仍需单独检查，响应式 HTML 不会使 A4 PDF 自动变成手机排版。
- 先选择与主题相符的字体、色板与图片，再按内容做层级。大标题、图文分区、路线／时间轴、比较表、卡片等用于表达信息关系；避免所有页面重复同一套卡片。没有真实数据就不做装饰性指标。
- 文字留在 HTML 中，摄影或生成图承担当下需要的视觉角色。图注用于帮助读者理解地点、产品或细节；调研依据和素材归属集中放在附带记录，以简洁链接关联。预约入口等实用内容保留在正文，不把制作说明和通用免责声明铺进页面。
- 屏幕导航、目录跳转、打印按钮可按需要增加，打印时移除阅读工具栏。简单手册优先自包含 CSS 与本地素材，无需为视觉效果引入前端框架。

参考 [水岸江苏](../examples/jiangsu-waterways/brochure.html)：三城六日旅行提案，使用许可摄影、城市专页、逐日安排和官方预约指引。它展示一种主题化设计，不要求后续手册沿用它的风格或页数。

需要探索视觉方向时，也可以先生成一页参考图，再以它的构图和视觉关系指导 HTML。重建时仍以原始资料核对文案、图表与参数，不能把生图里出现的文字和数据当作事实来源。这是可选的方向探索，不是每份 HTML 手册的前置步骤。

手机传阅的 PDF 必须在实际显示大小下核对可读性；A4 打印版的字号不能直接当作所有屏幕画幅的默认值。无合适照片时可用纯文字设计，不用无关或未获准的照片凑页。

## 检查与 PDF

```bash
node scripts/check.mjs --html brochure.html --product product.json --images images.json
# 含待确认内容的样稿：加 --mode draft
```

浏览器逐页查看、等待图片与字体加载，再打印 PDF：A4 纵向、无页边距、保留背景图形、关闭浏览器页眉页脚。若改过画幅，按实际 CSS 页面尺寸导出。分别检查桌面、约375px窄屏和打印媒体；测量正文实际字号、横向溢出、文字与页脚重叠，再查看截图。核对 PDF 页数与 HTML 页数、每页末尾内容、字体、图片和复制出的文字。字体放大、200%浏览器缩放或长段落重排时，不应丢失内容。

`examples/sustech-study-tour/brochure.html` 有 10 页与自定义构图，只作为 PDF 草稿示例；待确认事实和图像占位不是正式交付内容。

## 可编辑 PPTX 的边界

仅当用户需要时安装可选依赖并转换：

```bash
pnpm install --frozen-lockfile
node scripts/html-to-pptx.mjs --html brochure.html --output brochure.pptx
```

- 转换器输出 A4 竖版，支持 `page-cover`、`page-split`、`page-bleed`、`page-timeline`、`page-specs`、`page-closing` 六类语义版式；其他画幅使用 PDF 或专门的可编辑制作路线。
- 保留对应的内容 class：如 `cover-title`、`body-text`、`num-item`、`tl-item`、`spec`。它读取这些内容，不是任意 HTML/CSS 转换器。
- 自定义构图会**报错并停止**，不会生成缺页文件。时间轴超过 8 项需先分页；每页超过一张图片也需改为支持的结构或交付 PDF。
- 图片等比居中裁切；不复刻任意 CSS、渐变或 `object-position`。文字排版为可编辑近似稿，不承诺与 PDF 一致。
- 转换后检查全部页数与各类内容，逐页核对行程、参数、列表、标题和页脚；不是仅看到文件存在就通过。

品牌、页数计划、素材清单、目检结论和未解决事项可汇总到交付说明。
