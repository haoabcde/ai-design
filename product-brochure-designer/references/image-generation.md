# 生图设计：整张图与整页手册

生图工具可以完成整体构图、排印和字图关系，设计判断仍由 Agent 承担。先编辑内容并确定页面任务，再把信息关系与视觉表达交给工具；不能先设计一大块氛围图，再把剩余空间当作正文容量。使用宿主实际可用的工具与接口，不在 skill 中绑定会变化的模型名。

## 把设计关系写成画面

提示词先交代读者要得到什么、哪些准确内容支持它、这些内容怎样关联，再描述合适的画面语言。单独堆叠“高级、精美、统一风格”会把关键判断交给随机结果；细写光线与材质也不能弥补缺失的信息结构。

| 原本的模糊要求 | 可以落实的关系，按当前题材选择 |
|---|---|
| 内容有价值 | 写清本页的主张、事实／依据、关键条件和读者要找到的答案；资料不足时补内容，不用更多宣传句占位。 |
| 有主题特色 | 把真实的顺序、差异、部件或体验转成构图线索，使其参与理解，而不只增加题材图标。 |
| 有设计、有层次 | 明确阅读顺序、比较或连接关系，选择排字、取景、图形和疏密；材料与装饰按表达需要加入。 |
| 气氛合适 | 从真实场景与使用情境判断明暗、色彩面积、材质和生活线索；不能只替换色相。 |
| 字大且好看 | 区分识别主题的标题、连续阅读的正文与辅助标签；为正文留真实空间，说明安全边界和阅读目标。 |
| 多页统一 | 说清保留哪些身份与形式关系、这页承担什么任务、构图可以怎样变化。 |

不要把这些关系固化成一种画风。产品可以用轮廓、结构或材料建立识别；文化旅行可以从空间与生活节奏出发；强品牌任务也可以由既有字体与色彩主导。参考图的价值是减少关键关系的歧义，而不是让每页贴同一张背景。

## 设计简报

把当前任务中重要的项目写进提示词，不必每次填满长表：

- **用途与观看情境**：海报／封面／手册第几页，给谁看，希望记住什么。
- **准确内容**：需要出现在图中的逐字文案，以及主次关系；不能出现的额外文字或伪数据。
- **信息关系**：哪些是先后、择一、对应、比较或条件；哪些关系必须从画面中读懂。区分需要解释内容的图像和主要建立氛围的图像。
- **视觉方向**：表达上述内容的构图、排字、图像与气质；用户给了明确方向就保持它，装饰不能挤掉必要信息。
- **参考图角色**：哪张是产品实物、Logo、视觉风格或待编辑的成品。明确什么必须保持、什么可以变化。
- **画幅与输出**：目标比例、尺寸、关键安全区；最终检查实际像素尺寸，提示词中的数字不是工具已执行的证明。

完整提示词通常可以按“最终是什么、供谁使用 → 准确内容与层级 → 信息关系和空间安排 → 视觉语言与参考作用 → 交付边界”组织，不要求固定字段。明确交付一张平面成品，避免模型画成书本模型、透视纸张、设备截图或多张缩略拼贴；用户要求效果展示图时另按其用途制作。

信息不足时采用符合用途的合理视觉选择并说明关键假设；产品外观、日期、价格等关键事实不能靠补写提示词编造。

改图时把固定项与允许变化项分开：产品／人物的身份和外形、品牌标识与已确认文案通常需要保持；镜头、场景、光线或构图按本次目标改变。例如只改图注时，不应顺带更换产品造型；做新场景页时，也不必复制封面的构图。参考图用于保留产品身份还是借鉴风格，应在提示词中说清。

多页或需要反复修改的项目，在调用生图前保存每页完整提示词及其参考图角色。修改前同步提示词与版本记录，重试只处理未通过的页面；不要让成功页面被无必要地重新生成。

## 单图制作与修改

1. 根据明确简报生成；需要探索才做少量实质不同的方向。
2. 打开实际图片检查标题、字形、数字、Logo、主体结构、构图和裁切。
3. 针对具体问题编辑，明确“改变什么、保留什么”，必要时重新附带原始产品图。保留原始文件和选定版本，防止反复生成造成产品或风格漂移。
4. 若精确文案多次出错，不把错误图称为成品。可调整文本密度、使用可编辑排版层，或向用户说明当前限制；用户指定生图路线时不要悄悄替换为另一种交付。

图像生成可以直接排中文，但不能因模型能力增强就省去逐字核对。OCR 只能辅助，最终还要查看图中的实际字形与可读性。

### 先处理内容密度，再处理错字

海报保留传播所需的信息，手册按页面任务分配可读的内容。先保存原始事实，再编辑成准确文案与必要图解，不把“六日路线”压成几句游览感受，也不靠补长段落体现内容丰富。不为画面空间删掉必要条件，不要求模型自行概括价格、参数或预约规则。区分逐字文案与只供模型理解的说明，防止把说明画进成品。

把“正文要大”落实到最终使用尺寸。A4 连续阅读可从14–16pt的视觉尺寸试起；生图无法像 HTML 那样保证精确字号，应以导出的实际页面检查。缩到手机宽度再看必要信息；固定栅格页不会响应式重排，不能因原图放大可读就声称手机直读达标。密度不合适先调整页数、分组和图文占比。

定点编辑时保留实际通过的原图，把修改目标、其余固定项和参考角色写清。一次修正后重新检查整张图，留意旧字未删干净、无关文字变化和产品细节漂移；不能只检查改动的那一句。

## 生图版产品手册

### 先建立全书依据

按读者问题规划各页任务，不固定页数。先确认整本是否覆盖目的所需的内容，再整理逐页文案与关系；记录产品／主题身份和视觉依据。不能为了凑成精简页数，删去路线总览、选型依据或学习任务等关键页面。

多页项目需要续作或反复修改时，可用 [booklet.json 示例](../examples/fold-concept/booklet.json) 保存页序、每页完整提示词路径、图片和参考图角色；共同固定项放在可选的 `brief` 文本中。所有文件路径都相对清单文件。简单项目仍可直接按页序传图片，不必额外建清单。

逐页状态从 `pending`（尚未生成）到 `generated`（待检查），实际查看图片、核对文字与产品后更新为 `reviewed`。这是 Agent 的质量记录，无须额外请求用户批准；续作优先处理未完成或未通过的页面，保留已有通过的图像与提示词。

优先使用用户提供的真实产品图。没有实物图而设计虚构概念产品时，在项目资料中记录其设定，不把生成外观或性能写成已存在的事实；是否需要画面内标注按实际用途判断，不自动添加 AI 署名或免责文字。

### 逐页生成并延续一致性

先做一页能代表全书风格的页面，再以它和原始产品素材作为后续页参考。重复需要保持的产品身份、色彩与字体角色，同时说明本页承担的不同信息任务。不要每页从空白提示词独立随机开始，也不要让每页都复制同一布局。

把共同依据分成两类，通常在简短 `brief` 和逐页提示词中就能表达：

- **保持**：产品／主题身份、已确认文案、字体角色、色彩职责、图像材料、页边与导航细节。真实产品以原始实物素材为准，生成页不能替代实物依据。
- **随内容变化**：主体比例、取景距离、图文位置、留白、节奏与页面功能。例如路线总览需要清楚节点，场景页需要体验，参数页需要比较；不能为了变化而打乱可比信息。

封面与一张真实内容页一起检验体系。确认内容页能回答本页问题、文案和图解可读后再扩展，不能只用少量文字的封面判断全书可行。后续页以已选代表页为锚点，并说明参考约束哪些关系；装饰过重的参考会放大同样偏差，必要时重新生成内容结构，不强行继承旧版装饰。避免只接上一页造成误差逐页累积。

一次产出对应一个最终页面；若用户要双页跨页设计，再明确设计跨页。不要把模型画出的书本模型、透视展示图或整本缩略拼贴当作逐页成品。

每页完成后与全书对照：产品造型和细节、Logo、名称、字体角色、配色、页码与内容关系是否一致。需要校正某页时，不默认重做已经通过的页面。

如果整套看起来只是同一模板换字，回到各页的内容任务改变构图；如果像不同作者的独立海报，则回到代表页重申关键关系。连贯不等于每页同位置、同图幅；有意重复也可以帮助目录、对比和导航。

参考强度过高时，模型可能把布局与装饰也完整沿用。此时只说“构图不同”往往不够：明确参考只约束哪些关系，并把新的文字区、图片区、先后顺序写成空间安排。可以对未通过的页面做一次布局重排编辑，保留准确文案和视觉身份；重排后重新核对所有文字与阅读尺寸。示例中苏州页由上下结构改为左文右景，保留了同一套字体、材料与色彩，见其实际编辑提示词。

### 核对与 PDF 汇总

- 每页逐字核对文字与数据，检查重复、遗漏、额外虚构内容与主体结构。
- 统一最终页面尺寸与比例；不同尺寸页面合页前先处理，不拉伸产品或文字，也不无说明地裁掉内容。
- 根据指定页序将已通过的页面原图汇总为 PDF。PDF 工具可以做尺寸适配与合页；不要把缩略图当作原图导出。
- 打开最终 PDF 核对页数、顺序、清晰度、页面边缘与颜色。确认文字仍为栅格图的一部分，不能承诺可搜索或可编辑文字。
- 保存逐页原图、最终 PDF、页序与关键提示词／参考依据。多页项目可以用简短的 `delivery-notes.md` 说明路线和已做核查。

先对照原资料检查是否保留任务所需信息，再核对已有文字；OCR 无法发现编辑时整块删掉的内容。缩略总览看焦点、重复与变化，逐页按目标尺寸尝试找出预定答案。OCR 与实际画面不一致时回看具体字形，不把 OCR 成功或清单 `reviewed` 当作设计通过。单个案例不能证明长手册或其他题材的稳定性。

宿主没有现成合页工具时，可用可选 Python 依赖 reportlab 运行：

```bash
python3 scripts/images-to-pdf.py --images page-01.png page-02.png --output booklet.pdf
# 使用多页清单；依照 pages 数组顺序，仅在每页 reviewed 且相关文件齐全时导出
python3 scripts/images-to-pdf.py --manifest booklet.json --output reviewed-booklet.pdf
```

脚本按参数顺序合页，默认 A4，等比完整放置，比例不符处留白；报告实际像素与有效 ppi。它不生成、改写或校对图像内容。`--page-size native` 以首图的 96dpi 尺寸建立统一页面。可参考 `examples/fold-concept/` 的两页实测与提示词。

清单模式会检查提示词／参考文件存在、页面 id 唯一以及目检状态，不会自动判断文字是否正确、参考图是否实际使用或风格是否一致。不同页可以有意复用同一图片，例如封面与封底；它们仍按清单保留为独立页。清单中的 `pageSize` 可指定 A4／native，显式的 `--page-size` 可覆盖它；两种输入方式不能同时使用。

需要专业印刷、复杂参数表或频繁改文案时，根据实际任务建议 HTML 排版或专门设计工具；不因现有工具方便就把所有手册都强制改成 HTML。
