# HTML 手册的编辑与版面细节

用于 HTML 产品、研学、旅游手册，尤其是“排得整齐，但没韵味”的反馈。先读已有内容和实际页面；把这种反馈落实到文字、取景、节奏与细节的修改，不能只在提示词里增加“高级、有文化感”。

## 从内容与参考推导视觉语言

先判断本页值得读者停留的一个具体内容，再决定它的呈现方式。文化旅行可能是照片里的灯影与河岸，产品手册可能是一个精密结构，研学手册可能是一个值得现场观察的问题。气质从这些内容产生，不靠一组抽象形容词规定。

有参考时，先找出元素之间的关系：视觉焦点怎样建立，颜色怎样分工，图像怎样进入版面，材质和边角怎样在多页呼应，哪些形式来自真实使用过程。区分可见特征、对实现方式的推断和自己准备迁移的方法；一张截图不能证明原作使用了 HTML 或生图。

把参考拆成关系，再用当前主题重新作决定，通常可在简短的视觉简报或源文件中落实：

| 要决定的关系 | 如何落实 |
|---|---|
| 内容与情绪 | 想让读者怎样接近内容；从具体题材寻找图像与形式的线索，而非先选“国风／杂志风”的皮肤。 |
| 视觉母题与延续 | 一个可辨认的形态、材质或图像关系，怎样进入封面、内页和小细节；不必处处重复同一张背景。 |
| 主视觉与阅读面 | 图像、色面、文字的面积和前后层次怎样组织观看顺序；允许有理由的遮叠、越界和不对称。 |
| 形式与使用 | 卡片可以组织阶段，表格可以帮助比较或记录，留白可以容纳书写；根据真实任务决定形式。 |
| 统一与变化 | 字体角色、图片处理、边角和页码形成家族；内容密度和构图随页面任务改变。 |

这些关系共同构成作品的气质。衬线、大字、低饱和、圆角、阴影和留白都只是可选手段；不能把某个参考的配色或组件当作通用答案，也不默认“更克制”就更有设计感。

图片、插画或材质需要时使用已有授权素材或生图，文字、几何、裁切和版面关系则可在 HTML 中精确控制。让两者共同服务构图；准确正文和记录表不应被烘焙到一张整页位图里来冒充可编辑 HTML。

密集行程页负责查阅，城市或产品故事页负责引起兴趣；相邻页有不同的停留方式。同类产品需要比较时，稳定复用版式反而有用。以水岸江苏为例，水线的弧度可以转译为照片与阅读面之间的转折；配色还要回到当地真实的水面、建筑、花木与生活情境中判断。不要把一种色相当作地域气质，也不要把一套明暗结构固定到后续题材。

## 文案也要编辑

保留准确事实、预约要求与路线，把重复的介绍和空泛的抒情换成具体的观看或使用线索。文案可以有温度，但不要虚构亲历、人物原话、天气、功效或文化典故。

| 文字问题 | 修改的着力点 |
|---|---|
| 每页都写“慢一点、留一点时间、感受魅力” | 写出在哪里、看什么、如何安排。例如“第一晚去夫子庙秦淮河一带，第二天在钟山与南京博物院间择一”。 |
| 景点名和产品卖点排成一长串 | 选一个叙事重点，其余必要资料安排到行程、规格或预约页。 |
| 为了有韵味加入生僻词、无来源诗句 | 回到素材中的具体细节，用自然、准确的句子表达。 |
| 同一信息在引言、日程、提示里重复三遍 | 只在最适合查阅的位置完整说明，其他位置讲不同层次的内容。 |

## 精修真实的字图关系

- **取景**：先看照片里最有意思的关系，再定裁切。灯光与倒影需要同时留下，园林需要保住空间层次；不要先画圆框或窄条，再强塞任何照片。
- **文字**：标题按句意安排换行，检查孤零零的末字、标点位置与视觉重心。正文保持舒适字号，用栏宽、段距和编辑解决拥挤；重要行程不能退成小字。
- **图注**：地点、部件或观察细节应贴近对应图像。工具名、研究记录、作者名单不进入叙事；素材归属仍按 `image-policy.md` 集中处理。
- **细部**：线的粗细、序号位置、照片边缘、段落起点要形成关系。装饰可以共同建立情绪、文化气质和识别，不必每一笔都承载功能；检查它们是否属于同一套语言，再决定增加、调整或删除。

优先用 CSS Grid／Flex 与正常文档流表达结构。绝对定位用于有明确边界的叠字等局部关系；屏幕重排后恢复自然阅读顺序。HTML 的精确排版能力用于控制这些细节，而不是默认生成一组网页功能卡片。

## 用内页验证修改

先改一张暴露问题的真实内容页，按实际尺寸和相邻页一起查看。看文字是否值得读、照片是否保住了要表达的内容、页面是否有停顿与重点；再决定哪些关系值得延续。需要比较时保留同页修改前后的画面，不用更漂亮的封面替代内页证据。

同时检查窄屏阅读与打印结果。大字、内容完整、无溢出是交付基础，不能代替对作品气质的判断；已有认可的封面也不能自动证明所有内页获得认可。

实例见 [水岸江苏的 HTML 演进](../examples/jiangsu-waterways/design/directions.html)：参考思路迁移、日光与配色修订分别保存。用户认可了后续日光版；学习的是内容、排印、图像与空间的关系，不把该版本的配色和布局作为通用模板。
