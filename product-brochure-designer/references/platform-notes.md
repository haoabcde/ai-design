# 运行、导出与字体

## 运行

核心脚本使用 Node.js ≥20，JSON 输入不需要 npm 依赖。可选依赖 `pptxgenjs` 用于手册语义转换，`yaml` 用于 YAML 输入；需要时从 skill 目录运行 `pnpm install --frozen-lockfile`。

本项目不绑定特定 Agent 或生图模型，也不自动安装全局 skill。使用宿主实际提供的浏览器、图像与原生设计工具。没有渲染能力时，只能交付未验证草稿。

## 像素图

单页参考模板默认 1080×1440 CSS px。用浏览器工具等待字体与图片完成加载，截取 `.page` 元素；设备像素倍率可能影响实际 PNG 大小，读取导出文件尺寸后再交付。PDF 不能替代用户要求的 PNG。

## PDF

手册模板默认 `@page { size: A4 portrait; margin: 0 }`，并保留打印背景。打印时去掉浏览器页眉页脚，不再附加纸张边距。修改画幅后按实际 CSS 尺寸导出，核对页数与尺寸，避免浏览器缩放造成多页或白边。

## 字体

A4 模板提供 macOS、Windows 与 Linux 常见中文字体回退，但回退可能改变字宽与换行，必须实际查看。使用项目允许的本地字体时，可通过 `@font-face` 声明，确认字体文件加载与许可范围。PNG 中字体已栅格化；HTML 与可编辑文件的接收方仍需要相应字体或正确回退。

## 送印

浏览器输出通常为 RGB，并不自动满足专业印刷交付。按印厂要求确定物理尺寸、出血、裁切、安全区、装订和色彩处理；不要把页面内的安全边距当作真正的纸外出血。办公打印无须为了假想印刷需求增加流程。
