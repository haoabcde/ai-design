# 从用户参考学习 HTML 手册的设计思路

来源：用户在 2026-11-17 提供的四张手机 PDF 阅读截图。只有画面，没有原始 PDF 或源码；下面将可见特征与实现推断分开。用户明确要学习设计思路，不是把 skill 限定为这两种风格。

## 两组画面的共同方法

前两张偏深绿、暖橙和奶油白，使用弧形照片、色块与层叠纸面；后两张偏暖纸、墨色和淡彩，以线描、统一照片处理、细边框和朱红小标建立书卷气。它们的具体样式不同，但都有贯穿封面与内页的视觉语言。

| 可见的设计关系 | 体现的思路 | 在新主题中的迁移 |
|---|---|---|
| 字体、照片处理、边角、颜色在多页反复出现 | 用少量相互关联的视觉语汇形成整册身份 | 从新主题选择自己的语汇，检查它们是否能进入标题、图片、资料页和页码，而不是复制深绿或暖纸色 |
| 大图、色面、纸面和小标签有前后遮叠 | 通过面积与层次控制观看顺序，画面有实体感 | 先确定主视觉与阅读面，再决定哪一处跨过网格或色面边界；层叠应有主次 |
| 卡片用来表达行前／行中／行后，表格用于现场记录 | 形式来自使用过程与内容关系 | 在产品册中可能转为规格比较或操作步骤；不要因为参考用了记录表就给所有手册加表格 |
| 同组照片保持近似色调、边框与图注方式 | 把不同素材纳入共同语境 | 先选合适原作，再用一致的裁切、色彩与装裱关系组织，保留关键证据与真实主体 |
| 小标、页边框、分隔线和页码彼此呼应 | 细节能共同表达文化气质与阅读节奏 | 装饰可以承担气氛和识别作用，不必每一笔都解释一条数据；也不能只加无关图标 |

## 哪些可以由 HTML 完成

圆拱与圆角、照片裁切、印章式文字标记、框线、色块、页码角标、阴影、表格和准确文字都可以由 HTML/CSS 排版。图 1–2 的主要几何与层叠关系不必靠生图。

图 3 的山水线描与小插画需要图像素材；它们可能来自手绘、图库或生图，截图不足以确定来源。若新作品需要类似原创绘画，应调用适合的图像工具，再把它与 HTML 字体、色彩和构图一起设计。不能将“HTML 路线”理解成所有视觉都必须用代码画，也不能把整页截图当作可编辑 HTML。

## 对上一轮的修正

上一轮把“韵味”过多收窄为内容编辑、整齐的排印和克制的图文分区。三城页虽有差别，图像、色面、边角与页码仍没有形成足够完整的语言。增加抽象审美词或继续删装饰，不能自动解决这个问题。

本轮在既有江苏内容和已选水线封面中迁移方法：以钴蓝、暖纸和珊瑚色分工，让水线的弧度进入照片与页边细节；用主视觉与阅读面之间的层次建立停留顺序，再按路线、城市和行前资料的任务调整结构。它是一次迁移验证，不是新增固定风格。

手机阅读器界面、斜向水印和学校标识不属于要迁移的设计语汇。参考中的小字和重阴影也不直接照搬；保持已确认的大字阅读要求，并用实际页面判断装饰的强度。
